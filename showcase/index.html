SDK Visual Refresh – Before/After

Showcase for #211, part of epic #195. The mockups below show how the SDK changes Mosaic Rush, Sort Puzzle and Snake.

Representative mockups, not live screenshots. The SDK pieces are built: StartScreen (#205), GameResultScreen (#206), the feel kit (#207), the topbar CSS module and motion tokens (#208), and the design tokens (#209). The template update (#210) is still open, and no game has adopted the refreshed SDK yet, so the "after" panels show what the SDK provides, not a captured game. Live screenshots will replace them once the games adopt it. Full details are in before-after.md.

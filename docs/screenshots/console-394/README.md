# Console before/after screenshots (#394)

Each image tiles one console screen three ways: **before (dark only) | after, light | after, dark**. The old console had no light theme, so "before" is dark only.

The "before" build is `7c95180`, the "after" build is the commit that closes #394. Both were rendered at 1280x900 (390x844 for the mobile shots) with the same mocked API data. The data is invented; no production data is shown.

Screens: dashboard (and create form), studio (live, building, failed, empty, picker, confirm dialog, new-game modal), game settings (and delete confirm, draft), profile, and the mobile dashboard, drawer, studio and profile.
